# Solar-System-Simulator

El proyecto simula el movimiento de los planetas en nuestro sistema solar en el espacio.
Todas la unidades de "masa" se encuentran medidas en "masa con respecto a la tierra", es decir "1" se considera la masa de la tierra
Usando click derecho el usuario puede ver un menu con botones refiriendose a cada astro y uno para asteroides, al hacer click en un boton se muestra un submenu.
El submenu de un astro posee un campo para la masa, donde esta puede ser cambiada.
El submenu de los asteroides posee campos para la masa, velocidad inicial, direccion y posicion en la que se quiere crear, una previsualizacion del asteroide y su direccion se mostraran mientras esto se configura.
